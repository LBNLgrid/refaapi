# REFA API Documentation

Source for the REFA API documentation site: https://lbnlgrid.github.io/refaapi/

Companion to the [REFA Python module docs](https://lbnlgrid.github.io/refamodule/).

Build locally:

```bash
pip install -r requirements-docs.txt
mkdocs serve
```

Pushes to `main` deploy automatically to GitHub Pages via `.github/workflows/docs.yml`.
